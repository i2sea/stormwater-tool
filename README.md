# 우수 수리계산서 도구 (stormwater-tool)

우수관로를 넣으면 강우강도, 유입시간, 합리식 계획우수량, Manning 관로 검토, 종단면도·맨홀·평면도·유역도를 함께 만들고
수리계산서(워드·한글)와 계산표(엑셀), CAD 도면(DXF)으로 내보내는 웹 도구입니다. 브라우저 하나로 동작합니다(서버 없음).

- 아티팩트: https://claude.ai/artifact/RZzpRmBJQmQsMDf7gS4c4U
- 적용 기준·결정 사항: [`docs/적용사항.md`](docs/적용사항.md)

## 쓰는 법

| 파일 | 용도 |
|---|---|
| `dist/우수수리계산서.html` | 아티팩트에 올리는 파일 |
| `dist/우수수리계산서_단독.html` | 내려받아 크롬에서 바로 여는 파일 (입력은 그 브라우저에 저장) |

엑셀 읽기·쓰기(SheetJS)와 워드·한글 내보내기(JSZip)는 처음 열 때 cdnjs에서 받아오므로 인터넷이 필요합니다. 계산·도면·유역도는 오프라인에서도 됩니다.

## 소스와 빌드

`src/`의 조각을 순서대로 이어 한 HTML로 만듭니다.

```bash
./build.sh   # node --check 후 dist/ 두 파일 생성
```

| 파일 | 내용 |
|---|---|
| `head.html` | 화면(HTML·CSS) |
| `engine.js` | 계산 엔진: 강우강도, Kerby 유입시간, 합리식, Manning, 접합·판정 |
| `raindata.js` · `wamisdata.js` · `wamisup.js` | 도로 배수시설 설계 및 관리지침(2025) 강우 자료, WAMIS 지역빈도해석 확률강우량(615개 지점), 자료 갱신 |
| `app.js` | 입력 화면, 관로 입력표, 관로 계획 전체 자동(관경·경사·단차), 표 화살표 이동 |
| `draw.js` | 종단면도·단면도 그리기, 동수경사선, 맨홀 인출선, 도면에서 관저고 수정, SVG·DXF 출력 |
| `mh.js` | 맨홀 탭 (규격 자동/수동, 특수 사각, 여유고, 수량) |
| `plan.js` | 평면도 (실좌표 DXF) |
| `dxfin.js` · `basin.js` · `net.js` · `prof.js` | DXF 읽기, 유역도(지형 격자·D8·토지이용·하천), 계획도에서 관로망·노선 만들기, 도로 계획 종단 |
| `export.js` · `hwpxtpl.js` | 계산서 docx·hwpx, 계산표 xlsx, 도면 zip |
| `svdb.js` · `tpl.js` · `sample.js` | 계정 저장소, 엑셀 기본양식, 예제 |

## 주요 기능

- **강우강도**: WAMIS 확률강우량(1시간 미만 3가지 방법) · 지침(2025) 부록 표 · 확률강우량도(2011) 식
- **유입시간**: Kerby 식(N 고정 6구분), 5분 미만·경사 없음은 5분(지침 4.3.2), 노선별 적용
- **관로 검토**: 등류 수심 유속, 통수능(원형 만류·BOX 90%), 접합(단차 0.03~1.5 m, 역단차, 관경 감소, 인입관) — 토피는 표시만 하고 판정에 넣지 않음
- **관로 계획 자동**: 최소 계획관경부터 관경·경사·단차를 조건에 맞춤, 종점 관저고 지정(그 값 이상), 필요하면 상류·인입 노선을 올림(토피 부족 감수)
- **유역도**: 수치지형도(1:5000) 등고선·표고점 → 지형 격자, 관로를 출구로 소유역·흐름길, 토지이용(경지·건물·도로·경사), 하천·저수지(E002·E003·E005·G002)는 유출구, 계획 도로 종단 반영
- **계획도에서 관로 입력**: 폴리선 꼭짓점·끊긴 점·갈림점 = 맨홀, 외부처리 관은 별도 노선, 본선·지선·인입 관계 자동
- **도면**: 종단면도(맨홀 인출선·합류·방류 표기, HGL), 관로 단면도, 평면도, 유역도 — 화면 확대·DXF 출력
- **출력**: 수리계산서 .docx / .hwpx(아티팩트에서는 zip으로 묶어 저장), 계산표 .xlsx, CAD 도면 zip
